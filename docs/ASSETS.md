# 插画来源与交付状态

public/backgrounds 下五张 WebP 均由本项目使用 OpenAI 内置 ImageGen 生成，非第三方摄影或古画扫描。没有付费 API 运行时依赖。生成素材不冒充公共领域古画或第三方授权作品。

生成提示：宽幅中国淡彩水墨，宣纸留白，上半留空用于排字；春为柳树桃花燕子江水，夏为竹林荷塘，秋为枫叶芦苇明月，冬为雪山松梅；dawn 为旭日江水孤舟。所有图片无文字无水印，压缩为 WebP。

当前四季图片为共用降级插画，并未完成365幅逐日定制匹配。全年365条数据已覆盖且摘句不重复，但同一作品可摘选不同对句。多数白话译文、赏析及逐日意境匹配仍待人工编校。此版本不可标记为已达到需求的全部内容验收标准。

## 每日远程古画（2026-11-25 更新）

365 天已分别采用 365 件不同的克利夫兰艺术博物馆中国绘画，来自馆方开放接口 `department=Chinese Art&type=Painting&has_image=1&cc0=1`，只存链接和元数据，没有下载新图片进项目。CC0 状态来自每件馆藏记录。授权说明：https://www.clevelandart.org/open-access 。

固定映射在 `src/data/sources/artwork-links.json`；重新生成日历时会保留此映射。标题和馆方描述用于匹配诗句意象、季节，节日日期优先分配；匹配说明在 background.description。属于自动语义筛选，尚未逐幅人工审美复核，不保证每幅均为浅色或有足够留白，也不将一般意境关联冒充节日专属作品。

网络检查记录在 `artwork-verification.json`。链接可能随第三方服务变化；加载失败会回退到保留的四季 WebP。远程图片不一定支持 Canvas 跨域读取，导出失败时界面会提示。

前文“四季图片共用”描述仅对应旧版：目前五张生成图仅保留作为降级资源。译文与赏析编校缺口未在本次改动中处理。

## 当前版本：Picsum 自然风景（替换上述馆藏映射）

按用户最新许可，全年已采用365个不同 Picsum 固定图片ID，无随机seed。候选按目录缩略图筛选自然风景，并依据诗句意象和季节分配；不宣称照片为中国节日实景。`scripts/match-picsum.py` 可重建映射；`picsum-tags.json` 保存筛选标签，`picsum-catalog.json` 保存官方作者与来源。授权为 Unsplash License（https://unsplash.com/license），不是 CC0。

原有五张插画完整保留。网页加载失败或超时展示本地备用；高清照片加载前显示低清预览及加载状态。项目只保存新增图片的链接和元数据。
